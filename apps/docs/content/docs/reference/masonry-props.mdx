---
title: Masonry Props
description: Props specific to the lightweight Masonry component.
---

`Masonry` accepts all [Common Props](/docs/reference/common-props) plus these
props.

| Prop              | Type      | Default | Notes                                                                |
| ----------------- | --------- | ------- | -------------------------------------------------------------------- |
| `enableNative`    | `boolean` | `false` | Progressively enables CSS Grid Lanes after hydration when supported. |
| `columnClassName` | `string`  | -       | Class applied to each internal column wrapper in CSS-mode layout.    |

## Native CSS masonry

```tsx
<Masonry
  enableNative
  items={items}
  columns={3}
  gap={16}
  render={({ data }) => <Card item={data} />}
/>
```

`enableNative` is experimental and progressive. Masonix detects the current
[`display: grid-lanes`](https://drafts.csswg.org/css-grid-3/) syntax after
hydration. Browsers without support continue using the regular flex layout.
Native mode preserves the same fixed track width passed to each renderer.

Because browser support is still limited, do not depend on native mode for
layout correctness. Treat it as an enhancement and test it in every browser
you support.

## Column classes

```tsx
<Masonry
  items={items}
  columns={3}
  columnClassName="space-y-4"
  render={({ data }) => <Card item={data} />}
/>
```

Use `columnClassName` for column-level styling only. Use `itemClassName` or the
card component for item styling.
